# DARK DEPTHS

Бесконечный хоррор на выживание от первого лица. Unity, Android первым.
Игрок делает вылазки в тёмное здание: фонарик, слух, шум, риск эвакуации.

## Зафиксированные решения

| ID | Решение |
|---|---|
| D-01 | Камера: **3D от первого лица**. Top-down и 2.5D не рассматриваются. |
| D-02 | Движок: Unity (актуальная LTS), **URP**, **New Input System**. Версию зафиксировать в `ProjectVersion.txt`. |
| D-03 | Платформа: Android (Google Play), сборка IL2CPP / ARM64, формат `.aab`. |
| D-04 | Стиль: минималистичный low-poly, силуэтные враги. |
| D-05 | Мир: ручные модульные комнаты + процедурное соединение. |
| D-06 | Монетизация: только после MVP и только если основной цикл интересен. |
| D-07 | Потеря при смерти: 50% добычи вылазки (значение в конфиге). Постоянные улучшения не теряются. |
| D-08 | Выход из игры во время вылазки = смерть (применяются правила потерь). Восстановление вылазки не делаем. |

Числа в документах — **стартовые значения** для настройки, а не финальный баланс. Все они живут в ScriptableObject-конфигах.

## Глоссарий

| Термин | Значение |
|---|---|
| Вылазка (run) | Один заход в здание от входа до эвакуации или смерти |
| Профиль (profile) | Постоянный прогресс: ресурсы, улучшения, настройки |
| Состояние вылазки (run state) | Временные данные текущей вылазки: добыча, заряд, позиция |
| Комната (room) | Префаб с сокетами, из которых собирается здание |
| Сокет (socket) | Точка соединения комнат: позиция + направление + тип |
| Глубина (depth) | Номер слоя здания; управляет сложностью |
| NoiseEvent | Событие шума: позиция, громкость, радиус, источник |
| Слухач, Охотник, Засадник, Имитатор, Страж | Типы врагов (см. `docs/05_ENEMIES.md`) |
| MVP | Первая играбельная версия (см. `docs/08_ROADMAP.md`) |

## Открытые вопросы

- Минимальная версия Android (предложение: Android 8.0 / API 26).
- Нужна ли рекламная сеть или только покупки (решается на этапе 11).
- Режим «бесконечного выживания» без эвакуации — после MVP.
