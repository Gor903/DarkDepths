# 05. Враги и ИИ

Правило: начинаем с одного врага (Слухач) и базового набора состояний. Новые типы — только когда предыдущий работает надёжно.

## Реализация

- Навигация: `NavMeshAgent` (NavMesh строится для каждой собранной комнаты, см. `06_WORLD_GENERATION.md`).
- Логика: явный конечный автомат (FSM). Один класс на состояние, общий интерфейс `IEnemyState { Enter, Tick, Exit }`.
- Конфигурация: `EnemyDefinition` (ScriptableObject).
- Враг реализует `INoiseListener`.
- Обновление ИИ: тик 5–10 раз в секунду, не каждый кадр. Тики разных врагов разнесены по кадрам.

## Общие параметры `EnemyDefinition`

| Поле | Описание |
|---|---|
| `walkSpeed`, `chaseSpeed` | Скорости |
| `hearingMultiplier` | Множитель слуха (0 = глухой) |
| `sightRange`, `sightAngle` | Зрение |
| `lightSensitivity` | Насколько заметнее игрок с включённым фонариком |
| `attackRange`, `attackDamage`, `attackCooldown` | Атака |
| `investigateTime`, `searchTime`, `searchRadius` | Поведение поиска |
| `loseTargetTime` | Через сколько без контакта теряет цель |

## Состояния

| № | Состояние | Что делает |
|---|---|---|
| 1 | `Idle` / `Patrol` | Стоит или идёт по точкам |
| 2 | `Alerted` | Короткая реакция на шум/игрока (поворот головы, пауза 0.5–1.5 с) |
| 3 | `Investigate` | Идёт к источнику шума, осматривается `investigateTime` |
| 4 | `Search` | Обходит точки в `searchRadius` вокруг последней известной позиции, `searchTime` |
| 5 | `Chase` | Преследует цель по NavMesh |
| 6 | `Attack` | Бьёт в `attackRange` с `attackCooldown` |
| 7 | `Return` | Возвращается к патрулю |

### Переходы

| Из | Условие | В |
|---|---|---|
| Idle/Patrol | Услышан шум (perceived > порог) | Alerted → Investigate |
| Idle/Patrol | Игрок виден | Alerted → Chase |
| Investigate | Достиг точки, ничего нет, истёк `investigateTime` | Search |
| Investigate/Search | Игрок виден | Chase |
| Investigate/Search | Новый, более громкий шум | Investigate (новая цель) |
| Search | Истёк `searchTime` | Return |
| Chase | В `attackRange` | Attack |
| Chase | Нет контакта `loseTargetTime` | Search (у последней позиции) |
| Attack | Игрок вышел из `attackRange` | Chase |
| Return | Дошёл до точки патруля | Patrol |
| Любое | Враг оглушён/убит | `Stunned`/`Dead` (после MVP) |

### Восприятие

- **Слух:** `OnNoiseHeard` запоминает позицию и `perceived`. Порог реакции — `perceivedThreshold` (по умолчанию 0.15).
- **Зрение:** проверка конуса `sightAngle`, дистанции `sightRange` и `Physics.Linecast` до игрока. Если фонарик включён: `sightRange × (1 + lightSensitivity)`.
- Игрок в укрытии: не виден и не слышен, пока враг не в состоянии `Search` рядом с этим укрытием.

## Типы врагов

| Тип | Особенность | Этап |
|---|---|---|
| **Слухач** | Почти слеп (`sightRange` ~2–3 м), `hearingMultiplier` высокий. Идёт на шум. Учит тихому движению | MVP (этап 4) |
| **Охотник** | Видит игрока и преследует; теряет след при укрытии/смене маршрута | Этап 8 |
| **Засадник** | Прячется в точках засады, атакует при близости; видны косвенные признаки (звук, след, царапины) | Этап 8 |
| **Имитатор** | Воспроизводит шаги/скрип двери. Встречается редко. Источник звука помечен как ложный, но игроку этого не показывается | После этапа 8 |
| **Страж** | Охраняет комнату с редкой добычей, не уходит далеко от поста | Этап 8 |

### Стартовые значения Слухача

| Параметр | Значение |
|---|---|
| walkSpeed / chaseSpeed | 1.5 / 3.5 м/с |
| hearingMultiplier | 1.5 |
| sightRange / sightAngle | 3 м / 90° |
| attackRange / damage / cooldown | 1.2 м / 30 / 1.5 с |
| investigateTime / searchTime | 4 с / 10 с |
| loseTargetTime | 3 с |

## Спавн

- Точки спавна врагов задаются в префабе комнаты (`EnemySpawnPoint` с допустимыми типами и минимальной глубиной).
- Количество и тип определяются глубиной через `DifficultyCurve` (ScriptableObject).
- Не спавнить врага ближе 15 м к игроку или в видимости.
- Лимит активных врагов: 4 (MVP).

## Читаемость

- Игрок должен понимать, почему враг отреагировал: шум помечается в Editor Gizmos; в игре — звук и поведение врага (поворот головы).
- Враг не должен «читерски» знать позицию игрока. Исключение — явно заданное поведение глубокого врага.

## Тесты (EditMode)

- Переходы FSM на заглушках восприятия.
- Игрок вышел из зоны слышимости → Investigate завершается → Search → Return.
- Одновременные шумы → враг выбирает наибольший `perceived`.
