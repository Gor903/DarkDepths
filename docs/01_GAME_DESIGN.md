# 01. Геймдизайн

## Концепт

Игрок исследует тёмное здание с фонариком. Враги реагируют на шум, свет и поведение. Вылазки повторяются; здание открывает новые зоны, более ценную добычу и более опасных существ. Игрок улучшает снаряжение между вылазками.

**Главная особенность:** враг редко виден целиком. Игрок видит движение на краю луча, слышит шаги за стеной, замечает силуэт в конце коридора.

## Принципы

1. Атмосфера важнее детализации графики.
2. Свет, звук и тишина — игровые механики.
3. Звук помогает ориентироваться, но не единственный способ обнаружить угрозу.
4. Каждую минуту игрок выбирает: исследовать, прятаться, сражаться или эвакуироваться.
5. Прокачка даёт новые возможности, но не снимает напряжение.
6. Сначала маленький интересный прототип, потом контент, потом монетизация.

## Игровой цикл

1. Игрок входит в здание со своим снаряжением.
2. Исследует комнаты, слушает, проверяет укрытия.
3. Находит добычу, расходники, секреты.
4. Избегает врагов, отвлекает шумом или сражается.
5. С глубиной растут риск и ценность добычи.
6. Игрок решает: идти дальше или к выходу.
7. Эвакуация сохраняет добычу; смерть — теряет часть.
8. Игрок тратит ресурсы на улучшения и начинает новую вылазку.

## Правила вылазки

| Событие | Результат |
|---|---|
| Эвакуация | Вся добыча → профиль |
| Смерть | Теряется `lossPercent` добычи вылазки (по умолчанию 50%), остальное → профиль |
| Выход из приложения во время вылазки | Как смерть |
| Постоянные улучшения | Никогда не теряются |
| Снаряжение, взятое в вылазку | Расходники тратятся; экипированное улучшение остаётся |

Правила потерь показываются игроку **до** входа в здание.
Первая вылазка нового игрока: `lossPercent = 0` (мягкий старт, настраивается).

## Прогрессия

Принцип: улучшение открывает решение, а не только увеличивает число.

| Ветка | Примеры | MVP |
|---|---|---|
| Снаряжение | Ёмкость батареи, дальность луча, оружие | Да (2–3 улучшения) |
| Навыки | Тихая походка, слух, скорость взаимодействия | Нет |
| База | Хранилище, мастерская, лаборатория | Нет (только экран улучшений) |

Каждое улучшение имеет компромисс. Пример: мощный луч светит дальше, но быстрее садит батарею и заметнее для светочувствительных врагов.

## Рост сложности

Основной параметр — **глубина** (`depth`). Каждый шаг глубины может менять не более двух параметров из списка:

- тип и количество врагов;
- скорость и слух врагов;
- частота опасных событий;
- ценность добычи;
- освещение, доступность путей, состояние комнат.

## События и секреты

| Событие | Описание |
|---|---|
| Отключение света | Часть освещения комнат гаснет |
| Генератор | Запускается игроком, создаёт шум, открывает путь/свет |
| Закрытая дверь | Есть альтернативный маршрут |
| Скрытая комната | Фальшивая стена |
| Редкий контейнер | Ценное снаряжение |
| Повторяющийся звук | Слышен в нескольких комнатах (подсказка или ловушка) |
| Изменение поведения врага | Редко, на глубине |
| Нестандартная комната | Выбивается из архитектуры здания |

Правило частоты: событие в среднем не чаще, чем в одной из четырёх комнат. Не каждая комната содержит награду или угрозу.

## Зоны

| Зона | Содержимое | Особенность |
|---|---|---|
| Жилая | Квартиры, кухни, кладовые | Бытовые предметы падают и шумят; узкие проходы, укрытия |
| Медицинская | Палаты, лаборатории | Медресурсы; враги реагируют на свет или движение |
| Промышленная | Машинные залы, вентиляция, мостки | Механизмы маскируют шаги; опасные участки |
| Подземный комплекс | Бетонные коридоры, склады | Редкая добыча, сильные враги, мало путей отхода |

MVP: одна зона (жилая).
