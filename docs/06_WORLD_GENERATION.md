# 06. Мир и генерация

Здание собирается из вручную сделанных модульных комнат. Процедурно меняются только соединения, наполнение и события.

Сначала — небольшой набор комнат вручную. Генерацию расширять только после тестирования.

## Контракт комнаты (префаб)

Каждая комната — префаб со структурой:

```
Room_<Zone>_<Name>          (корень, компонент Room)
├── Geometry                (стены, пол, потолок; static)
├── Sockets
│   ├── Socket_N            (компонент RoomSocket)
│   └── Socket_E ...
├── Bounds                  (BoxCollider, isTrigger, слой RoomBounds)
├── LootSpawns              (LootSpawnPoint ×N)
├── EnemySpawns             (EnemySpawnPoint ×N)
├── EventAnchors            (EventAnchor ×N)
├── Hiding                  (укрытия)
└── NavMeshSurface          (запекается в редакторе или на сборке)
```

### `Room`

| Поле | Описание |
|---|---|
| `roomId` | Уникальная строка |
| `zone` | Жилая / Медицинская / Промышленная / Подземная |
| `minDepth`, `maxDepth` | Допустимая глубина |
| `weight` | Вес при случайном выборе |
| `tags` | `Start`, `Exit`, `Corridor`, `Safe`, `Risky`, `Secret`, `DeadEnd` |

### `RoomSocket`

| Поле | Описание |
|---|---|
| `direction` | Нормаль выхода (определяется поворотом трансформа) |
| `type` | `Door`, `Corridor`, `Stairs`, `Vent` — соединяются только совместимые типы |
| `width` | Ширина проёма (м); соединяются только равные |
| `isLocked` | Закрыт по умолчанию, ключ/инструмент/альтернативный путь |

Соединение сокетов: позиции совпадают, направления противоположны.

## Алгоритм генерации

Вход: `seed`, `zone`, `targetRoomCount`, `depth`.

1. `rng = new System.Random(seed)`. Вся случайность — только через `rng`.
2. Поставить комнату с тегом `Start`. Добавить её сокеты в список открытых.
3. Пока комнат меньше `targetRoomCount` и есть открытые сокеты:
   - выбрать открытый сокет (приоритет по глубине от старта — расти вширь и вглубь);
   - выбрать кандидата из комнат, подходящих по `zone`, `depth`, типу и ширине сокета, по весу;
   - выровнять кандидата сокетом к выбранному;
   - если `Bounds` пересекаются с уже поставленными → отклонить, попробовать другого (макс. 10 попыток);
   - принять: добавить новые сокеты в открытые.
4. Поставить комнату с тегом `Exit` на самом дальнем по графу узле (не дальше, чем `maxPathToExit`).
5. Закрыть оставшиеся открытые сокеты комнатами `DeadEnd` или заглушками-стенами.
6. Запечь/объединить NavMesh.
7. Расставить добычу, врагов, события (см. ниже).
8. Прогнать валидатор. При ошибке — новая попытка с `seed + 1` (макс. 5 попыток, затем fallback на заранее проверенный layout).

### Валидатор (EditMode-тесты обязательны)

- Все комнаты достижимы от `Start` (по графу и по NavMesh).
- `Exit` достижим.
- Нет запертых комнат без альтернативного пути или ключа.
- Нет пересечений `Bounds`.
- Нет открытых сокетов без заглушки.
- Есть минимум одна `Safe`-комната в пределах 3 переходов от старта.
- Путь от `Start` до `Exit` не короче `minPathToExit` и не длиннее `maxPathToExit`.

## Наполнение

| Что | Правило |
|---|---|
| Добыча | Точки `LootSpawnPoint` с пулом и редкостью; ценность растёт с глубиной |
| Враги | Точки `EnemySpawnPoint`; количество и тип из `DifficultyCurve` |
| События | Не чаще, чем в каждой 4-й комнате; не в `Safe` и не в `Start` |
| Секретные комнаты | 0–1 на вылазку; доступны через фальшивую стену |
| Укрытия | Минимум 1 на 2 комнаты |

Каждая зона обязана содержать: безопасные участки, рискованные маршруты, редкие находки.

## Управление памятью

- Комнаты за пределами радиуса (по графу ≥ 3 от игрока) деактивируются; уничтоженные — возвращаются в пул.
- Враги и предметы переиспользуются через пул.
- В любой момент загружено не более `maxLoadedRooms` (по умолчанию 8).

## Рост сложности по глубине

`DifficultyCurve` (ScriptableObject): по `depth` отдаёт:
- допустимые типы врагов и их количество;
- множители скорости/слуха;
- вероятность событий;
- множитель ценности добычи;
- вероятность отключённого света.

Правило: за шаг глубины менять не более двух параметров.

## MVP-набор

- 1 зона (Жилая).
- 8–12 комнат: `Start`, `Exit`, 3–4 коридорных, 3–4 жилых (спальня, кухня, кладовая, гостиная), 1–2 `DeadEnd`.
- `targetRoomCount` = 8–10.
