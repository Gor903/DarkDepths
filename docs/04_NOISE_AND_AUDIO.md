# 04. Шум и звук

Две разные системы:
- **Шум (Noise)** — игровая логика: кто что «услышал».
- **Звук (Audio)** — то, что слышит игрок.

Источник звука обычно создаёт и то и другое, но они независимы: звук можно воспроизвести без шума (фон), шум можно создать без звука (беззвучный триггер).

## Система шума

### Данные

```csharp
public readonly struct NoiseEvent {
    public readonly Vector3 Position;
    public readonly float Loudness;     // радиус слышимости в метрах при множителе 1
    public readonly NoiseType Type;     // Footstep, Door, ObjectImpact, Weapon, Machine, Event
    public readonly GameObject Source;  // может быть null
}
```

### API

```csharp
NoiseSystem.Emit(in NoiseEvent e);          // создать шум
interface INoiseListener {
    Vector3 Position { get; }
    float HearingMultiplier { get; }        // 0 = глухой
    void OnNoiseHeard(in NoiseEvent e, float perceivedLoudness);
}
```

`NoiseSystem` хранит реестр слушателей (регистрация в `OnEnable`/`OnDisable`). Без `FindObjectOfType`.

### Расчёт

1. Для каждого слушателя: `distance = |listener.Position − e.Position|`.
2. `effectiveRadius = e.Loudness × listener.HearingMultiplier × surfaceMultiplier`.
3. Если `distance <= effectiveRadius` → `perceived = 1 − distance / effectiveRadius`, вызвать `OnNoiseHeard`.
4. Стены (MVP): если между точками есть слой `Wall`, радиус ×0.5. Реальную акустику и звук по пути навигации — после MVP.

`surfaceMultiplier` берётся из материала поверхности под источником (`SurfaceType`).

### Громкость (стартовые значения, м)

| Событие | Громкость |
|---|---|
| Шаг: присед | 3 |
| Шаг: ходьба | 8 |
| Шаг: бег | 15 |
| Щелчок фонарика | 2 |
| Открытие двери | 5 |
| Скрипучая дверь | 10 |
| Падение предмета | 12 |
| Бросок (удар об пол) | 12 |
| Дубинка (удар) | 6 |
| Запуск генератора | 20 (непрерывно, пока работает) |
| Выстрел (после MVP) | 30 |

### Множители поверхности

| Поверхность | × |
|---|---|
| Ковёр | 0.6 |
| Бетон, плитка | 1.0 |
| Дерево | 1.1 |
| Металл | 1.3 |
| Стекло/осколки | 1.6 |

### Маскировка

Работающий механизм создаёт `NoiseMask` — зону, где все шаги игрока умножаются на 0.5 (параметр в конфиге). Враги внутри зоны слышат хуже.

### Отладка

В Editor — Gizmos: круг радиуса шума на 1 с после события, цвет по типу. Обязательно, иначе баланс не настроить.

## Пространственный звук

Используем термины «3D-звук» и «бинауральное позиционирование», не «9D».

Задача: игрок оценивает направление и примерное расстояние до источника.

### Реализация

- Все 3D-источники: `AudioSource.spatialBlend = 1`, rolloff Logarithmic или Custom, настроен `maxDistance`.
- Спатиализатор: встроенный Unity (Android поддерживает стереопанорамирование); HRTF-плагины — после MVP, если нужно.
- Реверберация: 2–3 пресета (малая комната, коридор, большой зал) через `AudioReverbZone` или mixer snapshots.
- Окклюзия (MVP): простой low-pass фильтр при стене между источником и слушателем (`AudioLowPassFilter`, cutoff ~800–1500 Гц).

### Слои звука

| Слой | Примеры |
|---|---|
| Фон | Вентиляция, гул, далёкие механизмы |
| Игрок | Шаги, дыхание, снаряжение |
| Враги | Дыхание, скрежет, шаги |
| Взаимодействие | Двери, предметы, поломки |
| События | Редкие сигналы опасности |

### Audio Mixer

Группы: `Master` → `SFX`, `Ambient`, `Music`, `UI`. Регуляторы громкости в настройках для SFX, Ambient, Music.

### Правила

- Звук имеет понятную причину. Исключение — Имитатор.
- Громкость не всегда максимальна; динамика важна.
- Нет внезапных оглушающих звуков. Лимитер на `Master`.
- Пул `AudioSource` (макс. одновременных 3D-голосов: 24, настройка).
- Тест на наушниках, динамиках телефона, нескольких устройствах.

### Доступность

Информация, важная для выживания, **дублируется визуально**:
- Направление сильного шума рядом → слабый индикатор на краю экрана (включается настройкой «Визуальные подсказки звука», по умолчанию вкл.).
- Приближение врага в погоне → видимая реакция (затемнение края, виньетка), без вспышек.
