# 09. Монетизация и релиз

Начинать только после MVP и только если основной цикл интересен без покупок (см. чек-лист в `08_ROADMAP.md`).

## Этап 11. Монетизация

**Зависимости:** этапы 1–10 завершены.

- [ ] **T11.1** Выбрать рекламную сеть, интегрировать SDK. В разработке — только тестовая реклама.
- [ ] **T11.2** Rewarded-реклама (добровольная) в местах, перечисленных ниже.
- [ ] **T11.3** Покупки (если нужны): каталог, восстановление покупок, серверная или локальная проверка.
- [ ] **T11.4** Экран согласия и настройки конфиденциальности (при необходимости по региону).
- [ ] **T11.5** Страница политики конфиденциальности (публичный URL).
- [ ] **T11.6** Проверка на реальном устройстве: реклама, покупки, поведение без сети.

**Готово, когда:** реклама не прерывает опасные сцены, покупки работают корректно, игра интересна без трат.

### Rewarded-реклама

Предлагается **только** на экранах итогов и меню:

| Награда | Где |
|---|---|
| Дополнительный контейнер ресурсов | Экран итогов после эвакуации |
| Сохранить часть потерянной добычи | Экран итогов после смерти |
| Бонусная награда за вылазку | Экран итогов |

Запрещено: показ рекламы во время погони, боя, исследования или любого напряжённого момента; принудительная (interstitial) реклама в вылазке.

### Покупки

| Допустимо | Примечание |
|---|---|
| Косметика фонарика и экипировки | Основной вариант |
| Дополнительные слоты хранилища | Удобство |
| Альтернативные комплекты снаряжения | Не сильнее открываемых в игре |
| Удобства, не нужные для выживания | |

Если продаются боевые преимущества, бесплатная игра остаётся честной и проходимой. Не создавать искусственных препятствий ради продажи.

### Архитектура

- Модуль `Monetization` изолирован: интерфейсы `IAdService`, `IPurchaseService`. Без SDK (в Editor и в тестах) подставляются заглушки.
- Отключение монетизации не должно ломать игру.
- Награды выдаются через `RunManager`/`Progression`, а не напрямую из SDK-колбэков.

## Этап 12. Google Play

**Зависимости:** этап 11 (или 10, если без монетизации).

- [ ] **T12.1** Уникальный `applicationId`, версия, `versionCode`.
- [ ] **T12.2** Android Build Settings, требуемые Google Play параметры target SDK, 64-bit.
- [ ] **T12.3** Подпись релиза: keystore (вне репозитория, с резервной копией), Play App Signing.
- [ ] **T12.4** Сборка Android App Bundle (`.aab`).
- [ ] **T12.5** Проверка на реальных устройствах (разные производители, версии Android, разрешения экрана).
- [ ] **T12.6** Материалы стора: название, описание, иконка, скриншоты, feature graphic.
- [ ] **T12.7** Заполнить в Play Console: возрастной рейтинг, Data safety, декларацию рекламы, политику конфиденциальности.
- [ ] **T12.8** Закрытое/внутреннее тестирование согласно требованиям для нового аккаунта.
- [ ] **T12.9** Релиз в production.

**Готово, когда:** релизная сборка прошла проверку Play Console, обязательные разделы заполнены, основные сценарии протестированы.

### Важно

Требования Google Play (target SDK, формат, объём тестирования, раскрытия) меняются. Перед этапом 12 сверить актуальные правила в Play Console и документации Google; не полагаться на значения из этого файла.

### Чек-лист перед отправкой

- [ ] Нет тестовой рекламы и тестовых ключей.
- [ ] Нет `Debug.Log` в горячих путях, нет отладочных меню.
- [ ] Игра запускается без сети.
- [ ] Сохранения не теряются при обновлении версии (миграции).
- [ ] Права Android — только необходимые.
- [ ] Политика конфиденциальности доступна по URL и указана в сторе.
