# 03. Игрок, управление, фонарик, предметы

## Камера

Вид от первого лица, 3D. Камера на высоте глаз, фонарик закреплён на камере (или с небольшим запаздыванием — настройка).

| Параметр | Стартовое значение |
|---|---|
| FOV | 70° |
| Высота глаз стоя | 1.65 м |
| Высота глаз сидя | 1.0 м |
| Покачивание камеры | выкл. по умолчанию, настройка интенсивности 0–100% |

## Передвижение

| Режим | Скорость | Громкость шума (м) | Примечание |
|---|---|---|---|
| Приседание | 1.2 м/с | 3 | Тише, ниже обзор |
| Ходьба | 2.5 м/с | 8 | |
| Бег | 4.5 м/с | 15 | Расходует выносливость |

Реализация: `CharacterController`. Выносливость: 5 с бега, восстановление 8 с (параметры в конфиге).

## Сенсорное управление

| Элемент | Расположение | Действие |
|---|---|---|
| Виртуальный джойстик | Левая половина экрана, появляется под пальцем | Движение |
| Область обзора | Правая половина экрана | Свайп = поворот камеры |
| Кнопка «Взаимодействие» | Справа внизу | Открыть, подобрать, использовать |
| Кнопка «Присесть» | Справа | Переключатель |
| Кнопка «Фонарик» | Справа | Вкл/выкл |
| Кнопка «Атака / бросок» | Справа | Использовать экипированное |
| Кнопка «Бег» | Над джойстиком или по смещению джойстика до края | Спринт |

Требования:
- Кнопки крупные (минимум 48 dp), не перекрывают центр экрана.
- Настройки: чувствительность обзора, инверсия оси Y, размер и положение кнопок, левша/правша.
- Safe area (вырезы, жесты навигации) учитывается.
- Мультитач: движение и обзор работают одновременно.
- Сначала базовое управление и тест на реальном телефоне. Новые действия — только когда базовые удобны.

Для тестов в Editor: клавиатура+мышь через тот же слой Input Actions.

## Фонарик

Один компонент `Flashlight` на `Spot Light`. Параметры в `FlashlightConfig` (ScriptableObject).

| Параметр | Стартовое | Описание |
|---|---|---|
| Intensity | 3 | Яркость |
| Range | 14 м | Дальность |
| Spot angle | 55° | Ширина |
| Battery capacity | 120 с | Время работы |
| Drain | 1 ед./с при включённом | Расход |
| Low battery threshold | 20% | Начинает слабеть и мигать (мягко, без стробоскопа) |
| Toggle noise | 2 м | Щелчок включения |

Поведение:
- Батарея 0 → фонарик гаснет, нужна замена батареи (расходник).
- Включение/выключение мгновенное, без анимации вспышки.
- Мерцание при низком заряде: плавное падение яркости, не резкие вспышки. Отключается настройкой «Снизить визуальные эффекты».

Улучшения (каждое с компромиссом):

| Улучшение | Плюс | Минус |
|---|---|---|
| Мощная линза | +Range | +Drain, заметнее для светочувствительных врагов |
| Широкий рефлектор | +Spot angle | −Range |
| Ёмкая батарея | +Capacity | +вес → медленнее бег (опционально) |

## Взаимодействие

Интерфейс `IInteractable { string Prompt; bool CanInteract(Player p); void Interact(Player p); }`.
Игрок бросает луч из центра экрана на дистанцию 2 м, показывает подсказку у центра.

## Предметы (MVP)

| Предмет | Тип | Эффект |
|---|---|---|
| Фонарик | Постоянный | См. выше |
| Батарея | Расходник | +заряд фонарика |
| Аптечка | Расходник | +здоровье |
| Бросаемый предмет (бутылка) | Расходник | Создаёт шум в точке падения |
| Одно оружие | Экипировка | См. ниже |
| Добыча | Ресурс | Валюта улучшений |

Оружие MVP: дубинка (ближний бой, тихая, короткая дальность). Выстрелы и другие громкие виды — после MVP.

Здоровье игрока: 100. Урон врагов по умолчанию 25–35. Регенерации нет.

## Инвентарь

MVP: простая сетка/список с лимитом слотов (по умолчанию 8). Предмет = ScriptableObject `ItemDefinition`. Состояние = `ItemStack { itemId, count }`.

## Укрытия

Шкаф или ниша: игрок входит (`IInteractable`), управление ограничено (обзор через щель), шум = 0. Враги не проверяют укрытие, пока не имеют причины (состояние Search). Подробнее в `05_ENEMIES.md`.
